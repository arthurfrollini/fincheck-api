# RAG + Retrieval Eval + LLM-as-Judge Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `POST /education/questions` answers from the BCB Caderno with API-verified citations; retrieval quality gated on every push; answer quality judged nightly.

**Architecture:** New `education` feature module (Clean Architecture). Local embeddings (transformers.js) behind an `EmbeddingProvider` token; chunks in pgvector via `$queryRaw` behind `KnowledgeChunksRepository`; answers via `LlmService.complete` with Citations API document blocks. Ingest is a script. Evals extend `evals/`.

**Tech Stack:** NestJS 11, Prisma + pgvector (`pgvector/pgvector:pg17`), `@huggingface/transformers@4.3.0` (`Xenova/multilingual-e5-small`, 384-d), `unpdf@1.8.1`, `@anthropic-ai/sdk`, Jest, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-16-ai-rag-design.md`

## Global Constraints

- Corpus never committed. `corpus/manifest.json`: `{ "title": "Caderno de Educação Financeira – Conteúdo Básico (BCB, 2ª ed., 2026)", "url": "https://www.bcb.gov.br/content/cidadaniafinanceira/documentos_cidadania/Cuidando_do_seu_dinheiro_Gestao_de_Financas_Pessoais/caderno_cidadania_financeira.pdf", "sha256": "e42aa64c16d7e35ccaba4c73b28f604873e442fa1b093f13cfc2ec056db90cc3" }`. Download cache dir `.cache/corpus/` (gitignored).
- Answer model `claude-sonnet-5-5`; judge `claude-opus-5-5`. `LLM_PRICING['claude-sonnet-5-5'] = { input: 2, output: 10, cacheWrite: 2.5, cacheRead: 0.2 }`.
- Retrieval: top-k = 6 for answers; `RAG_MIN_SIMILARITY = 0.8` (cosine similarity = `1 - (embedding <=> query)`). Embedding prefixes: `query: ` for questions, `passage: ` for chunks; normalized (mean pooling, `normalize: true`).
- Chunks: per page, paragraphs merged to 120–250 words, overlap = previous chunk's last paragraph on the same page, never crossing pages; strip lines equal to `CADERNO DE EDUCAÇÃO FINANCEIRA`, `SUMÁRIO`, `MÓDULO <n>`, and bare page numbers.
- Answer call: `max_tokens: 4096`, `output_config: { effort: 'medium' }`, document blocks `{ type: 'document', source: { type: 'text', media_type: 'text/plain', data }, title: 'Caderno de Educação Financeira (BCB), p. <page>', citations: { enabled: true } }`, then the question as a text block. No `output_config.format`.
- Never log question text or chunk text. `LlmFeature` += `'rag' | 'judge'`.
- Retrieval gate: no drop vs baseline on recall@5 (and report hit@1, MRR@10). Judge gate: −2 cases on 20.

## Review Focus

1. **Citation `document_index` → chunk mapping** off by one or wrong when chunks are reordered: a citation must map to the chunk passed at that index. Test in Task 5.
2. **Threshold short-circuit**: below-threshold questions must never call the model (cost + ungrounded answer). Test in Task 5.
3. **pgvector SQL injection / parameterization**: the query vector must go as a bound parameter, not string-interpolated. Test in Task 2 (asserts `$queryRaw` tagged-template usage, no `$queryRawUnsafe`).
4. **Re-ingest of the same document** must not duplicate chunks. Test in Task 6.
5. **Evidence snippet absent from corpus** must fail the query-set validation, not silently lower recall. Test in Task 7.
